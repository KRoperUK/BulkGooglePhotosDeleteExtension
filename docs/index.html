Built for clearing out a whole library

Google Photos has no “select all” or “delete everything”. This does the repetitive part for you — safely.

Batch delete at scale

Select everything in view or a fixed batch size. It scrolls the grid to keep loading more until the library is clear.

Dry-run preview

Selects and counts without deleting a thing, so you can confirm it targets the right items before you commit.

Live progress

Deleted count, batch number, current phase and elapsed time — so you always know exactly where a long run is.

Stop on a dime

A stop button halts the run immediately and leaves no stray selection behind. You stay in control the whole time.

Typed confirmation

Deletion is destructive, so a real run asks you to type to confirm — and it refuses to run on the Bin, where deletes are permanent.

No limits, no network

No daily cap, no upsell, no server. Everything runs in your browser on the page you already have open.

It collects nothing. There's no server to collect it.

The extension reads the Google Photos page in your browser to find the checkboxes and Delete button — the same page your browser already shows — and nothing ever leaves your device. No tracking, no analytics, no accounts.
